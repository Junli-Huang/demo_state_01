RULES

本版规则

  1. Attribute 持久存在；分离只会失去 Influence。
  2. 进入值达到 100，实体进入对应状态。
  3. 影响消失后退出值增长；达到 100，状态解除。
  4. State 提供事实；Condition 满足后由 Effect 修改属性。
  5. Burning 持续 5s 获得 Fire +1；退出 10s 后移除。
